## ✨ Features

### 👤 Customer

* 🔐 Register & Login
* 🛠️ Browse home services
* 👨‍🔧 View available technicians
* 📅 Book a technician
* 📋 Track bookings
* ❌ Cancel bookings
* 👤 Manage profile

### 👨‍🔧 Technician

* 🔐 Register & Login
* 🛠️ Manage services
* 💰 Set hourly rate
* ⭐ Manage technician details
* 📩 Accept or reject booking requests
* ▶️ Start jobs
* ✅ Complete jobs
* 👤 Manage profile

### 🏠 Available Services

🔧 **Plumber**
⚡ **Electrician**
🪚 **Carpenter**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Lalittesh/Seora-react.git
cd Seora
```

### 2. Install dependencies

**Frontend:**

```bash
cd client
npm install
```

**Backend:**

```bash
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file inside the `server` folder:

```env
PORT=5000
MONGODB_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_JWT_SECRET
```

### 4. Start the backend

```bash
cd server
npm start
```

### 5. Start the frontend

Open another terminal:

```bash
cd client
npm run dev
```

🎉 Open the local URL shown by Vite in your browser.
